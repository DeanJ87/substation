# Ignoring files

Test shots, an `_old` folder, a sub you never want to see: ignore them, and SubStation won't process them or
count them in datasets.

- **A folder**: Settings → Ignored, or **Ignore its folder** on a sub's detail panel.
- **File names like…**: Settings → Ignored, with a pattern such as `*_test_*`.
- **One sub**: **Ignore this sub** on its detail panel, or tick several subs in a dataset and choose
  **Ignore**.

An ignored sub stays ignored wherever it turns up, because it's recognised by its content.

**Undo** a rule under Settings → Ignored. Everything it held back is processed straight away.
